# HADI MOBILE

Premium mobile-first online store for HADI MOBILE.

## Included
- Mobile-first customer storefront
- Fresh white / deep-navy / cyan-blue-violet technology theme
- Dynamic categories + subcategories
- Product search and sorting
- Featured products
- Product detail modal
- Persistent cart
- WhatsApp checkout to +961 76 150 404
- USD pricing
- Secure Supabase admin authentication
- Product CRUD
- Category/subcategory CRUD
- Product image uploads
- Stock / featured / active controls
- Row Level Security policies
- GitHub Pages-ready static frontend

Start with `SETUP.md`.

## Main files
- `index.html` — customer store
- `admin/login.html` — admin login
- `admin/index.html` — admin dashboard
- `assets/js/config.js` — Supabase + WhatsApp configuration
- `supabase/setup.sql` — database/security setup
